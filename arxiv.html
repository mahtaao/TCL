Abstract

Uncovering independent components from electroencephalography (EEG) data is a critical pursuit in neuroimaging as it allows for causal discovery, capturing intricate brain dynamics, or simply separating neural signals from noise or artifacts. At the same time, many of the methods of causal inference are non-applicable directly to non-invasive brain recordings where the treatment effect cannot be directly measured.

In this study, we compare the representation gained by Temporal Contrastive Learning (TCL) with that of MNE source estimate algorithm. Building upon the foundation of TCL and nonlinear Independent Component Analysis (ICA), our methodology addresses the challenges of invariance, identifiability, and nonlinearity inherent in brain dynamics analysis. Our results reveal distinct patterns in component generation between Principal Component Analysis (PCA) and TCL, with the latter showing sparser coefficients as the dataset size increases. This work is a step towards finding invariant and human-interpretable representations for identifying robust biomarkers or phenotypes from EEG data.

1 Introduction

Causal representation learning aims to learn representations that capture the underlying causal mechanisms of the data. This field potentially promises invariant, identifiable, and nonlinear representations that can be disentangled, generalized, and interpreted. Invariance is crucial in neuroscience, where the goal is to identify representations that are shared across different modalities of data acquisition, conditions, or populations. Identifiability ensures that the learned representations are unique and meaningful. Nonlinearity is essential for capturing the complex dynamics of brain activity. Disentanglibility allows for the separation of underlying factors, while generalizability and interpretability enable the application of learned representations to new scenarios and the understanding of their meaning.

In this project, we focus on Time Contrastive Learning (TCL), a nonlinear Independent Component Analysis (ICA) method that has shown promise in learning disentangled representations of brain activity. TCL has been applied to Magnetoencephalography (MEG) data, but its applicability to Electroencephalography (EEG) data remains to be explored. We investigate the potential of TCL in learning disentangled representations of EEG data and explore its limitations and assumptions.

Our goal is to verify whether TCL can be used to learn meaningful representations of brain activity from EEG data, which can be used for further analysis and potentially aid in the diagnosis of phenotypic data. This project contributes to the broader goal of developing causal representation learning methods that can uncover the underlying mechanisms of brain activity and provide insights into the neural basis of cognition and behavior.

2 Related Work

2.1 Temporal Contrastive Learning (TCL)

Temporal Contrastive Learning (TCL) hyvarinen2016unsupervised is a method for training a feature extractor for time series data by using segment indices as labels to discriminate between different time windows. The process involves dividing the time series into segments, labeling each data point with its segment index, and then learning a feature extractor alongside a Multinomial Logistic Regression (MLR) classifier. This setup aims to capture the temporal structure and distribution differences across segments, facilitating unsupervised learning through classification. A Multilayer Perceptron (MLP) is typically used as the feature extractor because of its ability to model nonlinear relationships, making it suitable for learning from data in conjunction with the MLR. The primary goal of TCL is to train the feature extractor, with the MLR serving merely as a training tool without significance after the training phase.

2.2 SSL for EEG Data

Self-Supervised Learning (SSL) methods have been increasingly applied to EEG data to learn meaningful representations without explicit labels. These methods leverage the intrinsic structure of EEG signals to create surrogate tasks for training. For instance, contrastive learning approaches have been used to learn invariant representations across different EEG recording sessions or subjects. However, many SSL methods have yet to fully exploit the temporal dynamics inherent in EEG data, which is where TCL could offer significant advantages.

3.2 EEG Data

The dataset used in this study was obtained from the HBN (Healthy Brain Network) Biobank, a comprehensive data repository that includes multimodal brain imaging, electroencephalography (EEG), eye tracking, genetics, digital voice and video samples, and actigraphy data. From this dataset, we selected high-density EEG recordings from 30 participants.

The high-density EEG data were recorded in a sound-shielded room at a sampling rate of 500 Hz with a bandpass of 0.1 to 100 Hz, using a 128-channel EEG geodesic hydrocel system by Electrical Geodesics Inc. (EGI). The recording reference was at Cz (vertex of the head) and the impedance of each electrode was kept below 40 kOhm. Each participant’s head circumference was measured, and an appropriately sized EEG net was selected. The time to prepare the EEG net was no more than 30 minutes, and the impedance was tested every 30 minutes during recording, with saline added as needed. More details are given in Section 7.

The shape of the EEG data was (94,128,501)94128501(94,128,501)( 94 , 128 , 501 ), where 94 represents the number of epochs, 128 represents the number of EEG channels, and 501 represents the number of time samples. In the end, we only used 116 of the channels that were not marked as bad (these are the channels or timestamps that are prone to have too low of signal-to-noise ratio or in which the presence of spurious artifacts is detected).

This high-density EEG dataset provides a rich source of neural activity data that can be used to investigate various cognitive and neurological processes. As the ground truth, we took into account the source estimate based on the EEG data to localize the underlying neural sources.

3.3 EEG Source Reconstruction

The aim of this work is comparing the components of TCL with linear inverse methods for source reconstruction of EEG data. Specifically, we have used a currently private library developed in PPSP lab that uses minimum norm estimation (MNE) techniques that were mostly follow-ups on Jas et al. jas2018reproducible based on Automated anatomical labeling atlas 3 rolls2020automated and hence the activities of 116 regions of 2D brain surfaces were estimated based on sensor recordings.

4 Methodology

Our pipeline implementation involves four primary steps. First, we try to reproduce the results reported in the original paper (TCL hyvarinen2016unsupervised). Second, we prepare our data, both simulated data and EEG data. Next, we train a model to get a disentangled representation from mixed sensor data. Lastly, we study if there exists a sparse linear predictor that can predict the representation from our source construction (ground truth) based on representation obtained from TCL.

4.1 TCL Implementation

In the initial step, we seek to reproduce the findings outlined in the TCL paper hyvarinen2016unsupervised. However, the official code repository111https://github.com/hmorioka/TCL is outdated, relying on TensorFlow and utilizing an unsupported version of the library. Despite searching, we couldn’t find any updated PyTorch or TensorFlow implementations. Therefore, we decided to develop our TCL implementation in PyTorch, ensuring compatibility with the latest libraries. Our model is compatible with PyTorch’s stable version, which, at the time of writing this report, is 2.3.0. The code is available at https://github.com/poonehmousavi/TCL.

We follow the same configuration as described in the paper and the official GitHub repository. However, achieving performance close to the reported results necessitates tuning certain hyperparameters. We experiment with various optimizers, including SGD, Adam, and AdamW. We haven’t observed significant differences in their performance. Accordingly, we decide to proceed with a simple SGD optimizer. Unfortunately, the exact settings used in the paper are not explicitly provided. Based on the comments within the code, it appears they trained the model for numerous iterations. They specify the maximum steps as 7⁢e7𝑒7e7 italic_e5, corresponding to the number of iterations (mini-batches). 4.2 Data Preparation

The EEG recording is loaded using the MNE-Python library MNE-package, with tools for reading, visualizing, and analyzing EEG data. The recording is first cleaned by dropping the bad channels, as identified in the recording’s info attribute.

The anatomical-based calculation of the ground truth source reconstruction begins with loading the parcellation and inverse matrix (INV) data from the respective files. The parcellation data is a matrix that represents the division of the brain into distinct regions, while the INV matrix is used to transform the sensor data to source space. Both EEG recordings and inverse matrices are relatively big and the calculations initially demanded an order of 50 GB of memory for each participant. To address this issue and to improve memory efficiency, we select a specific time slice from the recording. The start and end times are set to 5 and 205 seconds, respectively, resulting in a 200-second window. The recording data is then resampled and converted to a float32 data type for further memory efficiency. We slightly reduced the number of picked channels (116 for each participant) but did not reduce the 500500500500 Hz temporal resolution as we suspected this could affect TCL performance drastically.

5 Results

5.1 Simulated Data Analysis

Figure 2 compares the performance of our version of the TCL model and the reported results in the paper. While the exact numbers may not align, a similar pattern can be observed. It’s evident that as the number of layers increases (indicating stronger nonlinearity in the mixing-MLP), training the feature-MLP and the MLR becomes more challenging. Moreover, the classification accuracy decreases with an increase in the number of segments. This decline occurs because, with a greater number of classes, some of them will inevitably have very similar distributions and are thus difficult to discriminate; this is why we computed the chance level as above.

5.2 EEG Data Analysis

We observe two separate patterns in the component generated by PCA and TCL. In PCA, we observed a coefficient matrix that would converge to a permutation pattern, whereas in TCL, as we increase the number of patients in the training set, we observe that the coefficients appear slightly more sparse (Figure 3). However, within the scale of the datasets we had for this project, the learning curves are not much affected by the size of dataset.

One can compare this result with the comparison of PCA and TCA on simulated data in Figure 5 and observe that this pattern might be inherent to the algorithm.

6 Conclusion and Future Work

A significant limitation of TCL is the assumption that the number of sources (num_sources) should be predefined. In practical applications, we may not know the exact number of sources involved, and our access is limited to the number of channels provided by the sensors we use. This assumption may not hold true in real-world scenarios. For instance, if there are more than 116 channels, which corresponds to the number of parcels, the additional channels will be disregarded. This discrepancy between the number of sources and channels is a critical aspect to consider for future improvements in TCL.

We initially took inspiration from the follow-up works of the authors of the seminal paper on TCL, and we are interested in exploring the potential of TCL in the context of EEG data. We have successfully implemented the model and trained it on both simulated and real EEG data. Our results show that the model can learn a disentangled representation of the data, which can be used for further analysis.

A meaningful experiment on this result is to see if the learned representation can be used to predict the labels given from the lab (e.g., pathologies, the age of the participant, the task they were performing, eyes being open or closed, etc.) as a classification task.

Time Contrastive Learning is a promising causal representation learning method as it is one of the rare machine learning methods that explicitly account for the temporal dependence of the data and relax the i.i.d. assumption. This is particularly important in the context of EEG data, where the temporal structure of the data is crucial. Additionally, the model is capable of learning a nonlinear representation of the data, important for capturing the complex dynamics of the brain. However, it’s important to note the limitations: while the model has been used in the literature for MEG data, the assumption of statistical independence of the sources may not hold for all neuroimaging data.

We believe that this method, if further improved and shown to produce invariant representations across different modalities such as fMRI, MEG, and ECoG data, could have significant implications for neuroscience. This becomes particularly important when we consider the difficulties of computing the source reconstruction of EEG and MEG data, which is nontrivial to verify and validate.

7.0.1 Parameters

The script uses the following parameters:

  • •

    random_seed: Seed for random number generation. Set to 0.

  • •

    num_comp: Number of components (dimension). Set to 116.

  • •

    num_segment: Number of segments. Set to 150.

  • •

    num_segmentdata: Number of data-points in each segment. Set to 500.

  • •

    num_layer: Number of layers of mixing-MLP. Set to 5.

  • •

    list_hidden_nodes: List of the number of nodes of each hidden layer of feature-MLP. Set to [264, 264, 264, 264, 116].

  • •

    initial_learning_rate: Initial learning rate. Set to 0.01.

  • •

    momentum: Momentum parameter of SGD. Set to 0.9.

  • •

    max_steps: Number of iterations (mini-batches). Set to 700,000.

  • •

    batch_size: Mini-batch size. Set to 500.

  • •

    moving_average_decay: Moving average decay of variables to be saved. Set to 0.999.

  • •

    checkpoint_steps: Interval to save checkpoint. Set to 100,000.

  • •

    decay_steps_init: Decay steps for initializing only MLR. Set to 50,000.

  • •

    dir_path: Directory path for saving experiment results. Set dynamically based on current time, number of layers, and number of segments.

  • •

    train_dir: Save directory. Set to dir_path.

    start_time: Start time of the experiment. Set to 5 for this report to eliminate the instrumental noise of EEG acquisition.
